# Indexing and Storage

## Indexing
- Background indexing by monitoring one or more folders.
- Detects adds, moves, and deletes.
- External sync pipeline deposits files into watched folders.

## Storage Layout
- Originals stored in source folders (read-only to the app).
- Derived assets stored separately (thumbnails, video transcodes, metadata DB).

## Stretch Goal
- Duplicate detection to identify lower-quality variants.
